# AGENTS.md

Notes for AI coding agents working on this repository. Read this before making changes. README.md covers setup and settings for people; this file covers rules and lessons learned that are easy to get wrong.

## Project summary

Riverside Town is a Roku screensaver written in BrightScript with SceneGraph. It shows a town beside a river with mountains behind it. Five scenery layers scroll at different speeds (parallax), four cars drive in two lanes, and a panel shows the time, temperature, and weather from the Open-Meteo API. The scene switches between day, dusk, and night palettes based on the real sunrise and sunset times.

## Writing rules

These apply to code, comments, commit messages, README.md, and this file.

- Keep every file plain ASCII. Do not use em dashes or the Unicode ellipsis character. Use commas, colons, semicolons, or separate sentences instead. If a non-ASCII character must appear in an image, write it as an XML character reference in the generator (for example, `&#201;` for the E in CAFE).
- Use plain, literal language. Do not use idioms, figures of speech, or clever phrasing.
- Keep README.md accurate when behavior, settings, or file layout change.

## Roku rules learned on this project

- Do not define `Main()` in `source/main.brs`. Roku requires screensavers to use only `RunScreenSaver()`. If `Main()` exists, Roku treats the app as a normal channel and does not list it under Settings > Theme > Screensavers. The manifest must also keep `screensaver_title` and `screensaver_private=0`.
- Do not mirror a node with a negative scale. Roku does not draw rotating children (the car wheels) correctly inside a group with a negative scale. To make a car face left, the code swaps to a mirrored body image (`car_<name>_left.png`), moves the wheels to `w - x`, and reverses the spin direction. Keep scale values positive.
- Network requests must run in a Task node. `components/WeatherTask.brs` does this with `roUrlTransfer` and the `common:/certs/ca-bundle.crt` certificate file.
- Animation interpolators find nodes by id through `fieldToInterp` (for example, `sedan_car.translation`). Animations created in code are appended to the scene root so the id lookup works. Keep node ids unique.
- Label text that is too wide is cut off with "...". When changing font sizes or text, check that the longest expected value (for example, "10:42 PM") fits the label width.
- Screensaver debug output is on telnet port 8087, not 8085.
- Roku does not give apps the device's ZIP code. The weather location is set with `m.LAT` and `m.LON` in `components/MainScene.brs` (currently ZIP code 46220).

## Artwork rules

- All images in `images/` are generated by `tools/generate_images.py`. Do not edit the PNG files by hand. Change the generator and run `python3 tools/generate_images.py` from the repository root.
- The color palettes for day, dusk, and night are in the `P` dictionary near the top of the generator. Planned seasonal palettes should be added there.
- Do not use the E-gineering (E-g) design system colors or fonts in this project unless the owner asks for them. They were removed on purpose. The removed values were #304C5F, #4F7D9B, #F5653D, and #E9EFF6.
- Each scrolling layer is 1920 pixels wide, and its left and right edges must line up so two copies repeat without a seam. When changing a layer's shape, make the y value at x=0 equal the y value at x=1920. For curves, also match the slope at both edges.
- Each layer is cropped to a horizontal band to save texture memory. The crop values in `CROPS` in the generator must match the `translation` and `height` of the matching strip in `components/MainScene.xml`.
- Layers must overlap with no gaps. A lower layer must reach below the top edge of the layer in front of it at every x position, or the sky shows through.
- The top of the river must start below the top edge of the hills, or it sticks up into the mountains.
- The sky is an 8 pixel wide gradient stretched to 1920 pixels. Keep it narrow.
- Car images do not include the wheels. Wheels are a separate image so they can spin. If a car's size or wheel positions change in the generator, update the matching entry in `m.carDefs` in `components/MainScene.brs` (`w`, `h`, `wheels`, `r`, and `bottom`).

## Scene behavior to keep consistent

- `m.cameraSpeed` must equal the `town` value in `m.layerSpeeds`. A car's on-screen speed is its `ground` speed minus the camera speed in the near lane (moving right) and plus the camera speed in the far lane (moving left).
- Car ground speeds are ordered on purpose: sedan fastest, then van and Jeep, then the old truck slowest. Keep that order unless the owner asks for a change.
- Only one car uses a lane at a time so that faster cars never overlap slower ones.
- The clock panel moves between the positions in `m.infoSpots` to protect TVs from burn-in. Keep each position fully on screen for the current panel width (580 pixels).

## Packaging

- Build the sideload zip from the repository root with `zip -r riverside-town.zip manifest source components images -x "*.DS_Store"`. The manifest must be at the top level of the zip.
- Do not commit zip files, `out/` (created by the BrightScript Language extension for VS Code), `build/` (preview images from the generator), or `.vscode/` (it can contain the Roku developer password).

## Testing

There are no automated tests. After a change:

1. Regenerate images if the generator changed.
2. Sideload the zip and select the screensaver under Settings > Theme > Screensavers. Use Preview to start it.
3. Watch the debug console on port 8087 for errors.
4. Check day, dusk, and night. To test a palette without waiting, temporarily make `currentPeriod()` return `"day"`, `"dusk"`, or `"night"` on its first line. Changing only the default sunrise and sunset values does not work, because the weather response replaces them. Remove the change before committing.
